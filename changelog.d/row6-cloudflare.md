kind: Row 6: Cloudflare Worker secret delivery
---
Place stored secrets as Cloudflare Worker secrets (`src/cloudflare.rs`, `secretant cloudflare plan|apply|verify MANIFEST`), written against Cloudflare's published API (2026-11-12): a preflight list of secret names proves the stored API token before any value is sent, then one bulk request (one new Worker version, all or nothing) carries the values; the ledger is updated only after Cloudflare accepts it. Worker secrets are write-only, so `verify` says set, unset or stale, not that a value matches. The token appears only in the Authorization header and values only in the request body; errors are classes (denied, not found, rate limited, unreachable, timed out, rejected) and never carry response text. Fake-API tests in `tests/cloudflare.rs` (7); two mutations (ledger recorded before the write, token placed in the URL) each fail tests. Adds the `ureq` dependency. Not published.
