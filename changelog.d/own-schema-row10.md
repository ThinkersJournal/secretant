kind: **BREAKING**: minimum Rust version 1.95; SecretAnt's own ConfigurAnt schema and the cycle check (row 10)
---
Adds `configurant.toml`, SecretAnt's own ConfigurAnt schema, for the two settings that exist today: `store.path` (`SECRETANT_STORE`, `--store`) and the secret `unlock.passphrase` (`SECRETANT_PASSPHRASE`). `tests/own_schema.rs` parses it with `configurant` 0.7.2 (a dev-dependency from crates.io), refuses any `source = "secretant:..."` entry (SecretAnt must not ask itself for the key it starts with, `docs/DESIGN.md` section 6.3) with a negative control that the check fires, and checks a canary passphrase appears neither in the help text nor in the loaded configuration's `Debug`, with a positive control that it was supplied. `tools/stamp-extra.txt` keeps the schema's `version` current at stamping. No runtime change. The minimum Rust version rises from 1.88 to 1.95 because `configurant` 0.7.2 requires it (permitted by CireSnave 2026-10-08); the CI job "Builds on the declared minimum Rust version" reads it from `Cargo.toml` and checks it.
