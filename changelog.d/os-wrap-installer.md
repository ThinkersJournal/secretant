kind: the installer and command line offer the OS wrap on macOS and Linux (row 9 slice 2)
---
`secretant::OS_WRAP_SUPPORTED` says whether this build can make an OS-bound wrap (Windows always; macOS and Linux with the `os-keystore` feature). `installer::plan_store` refuses an OS wrap only where it is false, instead of everywhere but Windows, so `secretant init --add-os`, `--os` and the installer's `os_wrap` work on a Keychain or Secret Service. `tests/installer.rs::the_os_bound_wrap_is_added_when_asked` runs on Windows and, in `.github/workflows/os-store-probe.yml`, on macos-latest and ubuntu-latest with `SECRETANT_OS_WRAP_REQUIRED=1`; elsewhere it skips loudly. The README now states the 0.2.0 Breaking change (minimum Rust 1.95) and the `os-keystore` feature. The `systemd-creds` wrap is not started.
