The command line gains the row 7 commands. `secretant backup DEST` copies the store file as it is (ciphertext, owner-only, never over an existing file) and needs no unlock; `restore-test BACKUP` opens it and decrypts every version, printing counts only; `restore BACKUP [--replace]` checks the backup first, refuses to replace a store unless asked and keeps the old file as `.prev`; `doctor [--header-only]` prints fixed-sentence findings (no name, no path) and exits 1 on a failure; `export BUNDLE` writes every entry and version to a new store file under its own passphrase (asked twice, or `--bundle-passphrase-stdin`); `import BUNDLE` is a dry run listing names and version counts, and `--apply` imports, with `--conflict keep|replace` for names already present (without a choice a conflict refuses and writes nothing; nothing is ever deleted). Verified by `tests/cli.rs`: the backup and the bundle are searched for the recovery key, passphrase and value in plain, bare, upper, lower, hex, base64 and UTF-16 forms (with a planted-text control); a backup that leaks the passphrase and a restore that skips the replace check were each made and each failed a test. Not published.
